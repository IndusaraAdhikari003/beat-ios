# Beat for iPhone (iOS 15+)

Local songs (import / Files app), playlists, favourites, hide songs, sleep timer, light/dark theme,
YouTube search + recommendations + link/playlist paste, autoplay similar songs, background play + lock screen controls.

## Get the IPA (no Mac needed)
1. Make a GitHub repo (PUBLIC is fine, there are no secrets here, and public repos get free Mac build minutes).
2. Upload ALL files (including the hidden `.github` folder) to the `main` branch.
3. Actions tab -> "Build iOS IPA" runs (about 5-10 minutes).
4. Open the finished run -> Artifacts -> `Beat-ipa` -> unzip -> `Beat.ipa`.
5. Install it on the iPhone with Sideloadly or AltStore (signs it with your Apple ID).

## Add songs
- In the app: Songs tab -> Import songs.
- Or: Files app -> On My iPhone -> Beat -> copy mp3 files in. Then pull down on the Songs list.
